# “带上”首次使用流程重设计

## 目标

让第一次打开产品的用户无需阅读教程，也能在几秒内完成“选择场景并进入清单”。普通流程不暴露“模板、写回、变更汇总”等内部概念。

## 核心模型

选择去哪 → 对照清单 → 完成。

## 首页

- 标题为“这次要去哪？”。
- 直接展示“周末出游、商务出差、一周旅行”三个现成场景。
- “创建自己的场景”作为次要入口。
- 有未完成清单时，顶部仅显示“继续上次准备”。
- 不出现“模板、管理模板、开始准备”等术语。

## 清单页

- 顶部仅显示场景名称、完成数量和简洁进度。
- 物品按“证件、数码、衣物、洗漱”分组，点击即可勾选。
- 底部固定“添加物品”和“完成准备”。
- 编辑、删除、放弃等低频操作收进右上角菜单。
- 添加物品时允许搜索以前用过的物品，但不解释数据来源。

## 完成页

- 首要反馈为“准备完成，可以出发了”。
- 没有新增物品时直接结束。
- 有新增物品时，以自然语言逐项询问，例如“以后周末出游也带电脑充电器吗？”。
- 操作仅为“以后也带”和“仅本次”。
- 删除和修改默认只影响本次，不要求用户处理。

## 防止内容堆积

- 首页优先显示最近使用的少量场景。
- 临时新增物品默认不污染场景。
- 同名物品自动识别，避免重复。
- 长期不用的场景收进“更多”。

## 原型验收标准

- 新用户第一眼能理解场景卡片可点击。
- 从首页到清单只需一次点击。
- 主流程中不存在“模板、写回、变更汇总”等产品术语。
- 三个页面均只有一个视觉上最强的下一步操作。
